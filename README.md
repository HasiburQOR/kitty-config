# 🌸 Kitty Terminal Configuration

A high-performance, vibrant dark-themed terminal configuration for Fedora.

## 🌟 Features
- **Theme:** Custom high-contrast Neon/Sakura Dark palette.
- **Font:** JetBrains Mono Nerd Font for clean coding ligatures.
- **Opacity:** 90% background opacity for a modern, sleek aesthetic.

## 🛠 Installation Guide

If you ever need to restore this configuration on a fresh system, run these commands:

### 1. Install Dependencies
```bash
sudo dnf install git kitty google-jetbrains-mono-fonts -y
